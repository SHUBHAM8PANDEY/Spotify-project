# Spotify-project

Pulse Room is a static music-player demo with six original instrumental loops, search, and a library saved in the current browser. Audio and styles are included in the repository.

Open `index.html` to run locally. No dependencies or build step are required.

## GitHub Pages

In [repository Pages settings](https://github.com/SHUBHAM8PANDEY/Spotify-project/settings/pages), choose **Deploy from a branch**, select **main** and **/(root)**, and save. After deployment, open the [project site](https://shubham8pandey.github.io/Spotify-project/).
